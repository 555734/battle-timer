# Runner + God v0.3

Godot 4.7.2 Android asymmetric local co-op prototype.

## Roles
- Runner: lower-left movement pads + lower-right jump.
- God: interact directly with the world above the control strip.
  - Drag through empty space to draw a temporary bridge.
  - Drag a blue bridge to reposition it.
  - Tap an enemy to freeze it for 4 seconds.
- Gold orbs refill God Power.

The level is built around gaps and enemy placements that require cooperation. The prototype includes parallax scenery, procedural character/enemy rendering, particles, screen shake, synthesized sound effects, checkpoints, title/finish presentation, coyote time, jump buffering and touch vibration on Android.
