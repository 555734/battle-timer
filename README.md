# PROJECT BREAKLINE — Android native MVP

HTMLではなく、Android SDK・Java・OpenGL ES 2.0で作ったネイティブ版です。ゲーム世界は実際の3Dメッシュと透視投影で描画します。

## 実装範囲

- 縦画面固定、左右ドラッグによる隊列移動
- 前方自動射撃、2〜3個の数字付き樽から1つを選ぶ4種の即時報酬
- ウォーカー・ランナー・ヘビーの敵3種、仲間の増減、勝敗画面
- 突進と地面強打を予告表示して回避するボス戦
- 12ステージ、4種の環境カラー、端末内コイン、永続強化3項目
- 一時停止、OS復帰、安全なデータ初期化、効果音・振動・画面揺れ設定
- OpenGL ES 2.0による実3Dの橋／街／水面背景、ガードレール、道路、立体樽、立体キャラクター
- 3Dカメラ、ライティング、霧、影、低ポリゴンの群衆、銃弾・爆発・ボス攻撃エフェクト
- リムライト、距離フォグ、動く水面反射、空・雲・街の窓明かり、接地影、カメラの走行ボブ
- CanvasはタッチしやすいメニューとHUDだけに使用。ゲーム世界はCanvasの疑似3Dではありません
- `SharedPreferences` によるローカル保存
- 通信・ログイン・基地建設・PvP・広告・課金なし
- `INTERNET`権限なし（完全オフライン）

## 起動方法

1. Android Studioでこの`native-android`フォルダを開く
2. Android SDK Platform 35を選択してGradle Sync
3. Android端末またはエミュレータを縦画面で起動
4. `app`をRun

最低対応APIは26です。リリースビルドはAndroid Studioの`Build > Generate App Bundles or APKs`から作成できます。

## 重要な設計判断

この版はコアゲームループを最初から最後まで遊べる、完全オフラインのネイティブMVPです。3Dキャラクター、道路、敵、VFXはコード生成メッシュなので、外部素材や追加ダウンロードを必要としません。ゲーム状態とローカル保存をJava側に集約しているため、次工程では独自アートと音素材を差し替えられます。
